# mengto.com

A page-flipping sketchbook of Singapore, in one static HTML file.

- `index.html` — the whole page: layout, styles, and the book, loupe and page-turn code
- `sketchbook/` — sketches, paper textures, botanical art and subset fonts

No build step and no external requests. Open `index.html` directly, or serve the
folder over http for the fonts to load with the right headers.

Deployed on Netlify from `main`: https://mengto.netlify.app
