这个页面需要保存接口：请改用 python tools/admin.py 启动本地服务（地址不变，还是 4173 端口）， 再刷新本页。只跑 python -m http.server 时只能看，不能存。
五种入册方式：「照片铺满纸面」最常用，但会裁掉放不下的部分（竖图裁得最多）；竖图选「照片完整放入 · 周围留白」，整张照片等比缩小贴在册子上；想不留白、整页都是照片，选「照片整页 · 自适应不留白」—— 册页比例会跟着照片走，翻开时整页铺满；「右页照片 · 左页题字」自动在左页竖排题字并盖印； 「原图整幅」适合你自己做好了的整幅画稿。 文件名自动生成，无需填写。输出分辨率只作用于新合成的卡片；本次会话里上传过原图的卡片会按 新分辨率重新合成，之前已保存的旧页想升级清晰度，重新拖一次原图再写入即可。
